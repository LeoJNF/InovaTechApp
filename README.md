# Sistema De Gerenciamento para controle e emissão de folha de pagamento
# Descrição:
Com base no levantamento de requisitos feito no semestre anterior, de todos os processos internos para a digitalização do cálculo da folha de pagamento e geração digital de todos os documentos envolvidos neste processo do setor de RH e departamento pessoal, com o objetivo de criar um sistema e automatizar a folha de pagamento. 
# Ferramentas utilizadas:
  - Python 3.11.5
  - Kivy 2.2.1, KivyMD 1.1.1
