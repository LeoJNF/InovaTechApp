# Sistema De Gerenciamento para controle e emissão de folha de pagamento
App em desenvolvimento com o objetivo de criar um sistema de automatização de folha de pagamento para o setor de RH e do departamento pessoal
# Descrição:
Com base no levantamento de requisistos feito no semestre anterior, de todos os processos internos para a digitalização do cálculo da folha de pagamento e geração digital de todos os documentos envolvidos neste processo do setor de RH e departamento pessoal. 
#Ferramentas utilizadas:
  - Python 3.11.5
  - Kivy 2.2.1, KivyMD 1.1.1
